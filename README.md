# Personal Portfolio - Alan Miranda

![Portfolio Preview](/public/preview.png)

This is my personal portfolio built with React, TypeScript, and Styled Components. The project features a modern and responsive interface with smooth navigation and elegant animations.

## Technologies Used

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Styled Components](https://styled-components.com/)
- [React Router](https://reactrouter.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Phosphor Icons](https://phosphoricons.com/)

## Features

- Responsive design with mobile support
- Smooth navigation between sections
- Transition animations
- Mobile menu with a side panel
- Modern and minimalist interface

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/AlAnNuB/portfolio
```

2. Enter the project directory:

```bash
cd portfolio
```

3. Install the dependencies:

```bash
yarn install
```

4. Run the project:

```bash
yarn dev
```

5. Open `http://localhost:5173` in your browser

## Responsiveness

The project is responsive and adapts to different screen sizes:

- Desktop: Horizontal navigation with a complete menu
- Mobile: Hamburger menu with a sliding side panel
